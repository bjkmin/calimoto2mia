Calimoto → Aprilia MIA

Rewrites a Calimoto GPX export into the Kurviger-style shape the MIA app accepts (named waypoints + track line). Fully offline — your file never leaves the phone.

Download converted .gpx
How to use
  1. In Calimoto: export the tour as GPX (share → send to file / save to Downloads).
  2. Open this page (bookmark it — it works offline), pick the .gpx file.
  3. Convert, then tap Download.
  4. Open the downloaded file with the Aprilia MIA app (or import it in the app from the Downloads folder).
